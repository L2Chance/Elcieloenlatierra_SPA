**Sistema de gestión de SPA**

Como parte de una asignatura en la UTN FRRE, se nos encomendó desarrollar una página web para la administración integral de un SPA. El sistema debía permitir la gestión de servicios, turnos de clientes, profesionales, roles de usuario, simulación de pagos, respuestas automáticas mediante un chatbot, entre otras funcionalidades.

El proyecto fue desarrollado con una arquitectura monolítica, utilizando Python y Django como base principal, junto con HTML, CSS, JavaScript y una integración parcial de Tailwind CSS mediante Django-Tailwind.
